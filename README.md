BuySignal provides a platform for UK consumers to discover daily deals and price drop alerts across over 20,000 products from major retailers such as Currys, Argos, Very, John Lewis, and JD Sports. Users can browse fresh deals, set up free price alerts, and stay informed about the best discounts available in the UK market. The service aggregates offers from more than 20 retailers, delivering up-to-date information to help shoppers save money and find the best buying opportunities.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for BuySignal: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
